# AMS5_TradeHolding
Desenvolvendo o protótipo de um negócio ficcional inspirado pela empresa Binance. O projeto é focado em uma empresa chamada Lunaria, cuja razão social é fornecer uma plataforma de atividades econômicas envolvendo criptoativos, incluindo seus serviços de atendimento. Seu objetivo e diferencial no mercado é atender a maioria das pessoas interessadas em criptomoedas com linguagem simples e clara, além de um apelo mais educacional, limpo e útil para o dia-a-dia.

A solução integra diversas tecnologias modernas: backend em .NET seguindo princípios de Clean Architecture, frontend web em Next.js com Tailwind CSS, aplicativo mobile em React Native e um chatbot de suporte implementado em Flask (Python). Esse conjunto de ferramentas permite demonstrar, de forma prática, como arquiteturas distribuídas podem sustentar serviços financeiros complexos, mas com foco na clareza e na experiência do usuário final.
